مصروفي PRO — نسخة الآيفون

هذه نسخة تطبيق ويب تعمل على iPhone من خلال Safari دون Python.

لتثبيته على الشاشة الرئيسية:
1. ارفع محتويات المجلد (index.html و manifest.webmanifest و icon.png) إلى استضافة HTTPS مثل GitHub Pages أو Netlify.
2. افتح رابط الموقع المنشور في Safari على iPhone.
3. اضغط مشاركة ثم «إضافة إلى الشاشة الرئيسية» (Add to Home Screen) ثم إضافة.
4. افتح أيقونة مصروفي وسجل دخلك الافتتاحي والمصاريف.

هام: حفظ البيانات محلي داخل متصفح الهاتف وليس سحابيًا. خذ نسخة احتياطية JSON من الإعدادات بشكل دوري، خاصة قبل حذف الموقع أو تغيير الهاتف. بيانات تطبيق الكمبيوتر لا تنتقل تلقائيًا إلى الهاتف.
