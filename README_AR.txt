مصروفي ULTRA — إصدار الآيفون والكمبيوتر

التثبيت على GitHub Pages:
1. افتح مستودع GitHub masroofi-pro.
2. اختر Add file > Upload files (أو uploading an existing file إذا كان المستودع فارغًا).
3. ارفع الملفات الأربعة مباشرة في جذر المستودع: index.html و icon.png و manifest.webmanifest و sw.js.
4. اضغط Commit changes.
5. Settings > Pages > Source: Deploy from a branch > main > /(root) > Save.
6. افتح https://USERNAME.github.io/masroofi-pro/ من Safari، واستبدل USERNAME باسم حسابك.
7. مشاركة > إضافة إلى الشاشة الرئيسية.

مميزات: تصميم داكن بالعربية، دخل ومصاريف مع ملاحظات، رصيد حي، بحث، فلاتر، إحصائيات يومية، رسوم بيانية، ميزانيات شهرية، أهداف ادخار، دفعات متكررة، تصدير CSV ونسخ JSON واستعادة، PWA للاستخدام دون اتصال بعد التحميل الأول.

تنبيهات:
- البيانات تُخزّن على الجهاز نفسه داخل المتصفح، ولا تتزامن بين الأجهزة.
- تغيير أو حذف بيانات Safari قد يحذف المصاريف. انسخ JSON احتياطيًا دوريًا.
- تغيير العملة لا يحوّل المبالغ؛ يغير رمز العملة فقط.
- الأهداف مستقلة ولا تخصم تلقائيًا من الرصيد.
- المصروفات المتكررة تسجّل عند فتح التطبيق أو تفعيله فقط، لا في الخلفية.
- إذا استخدمت النسخة القديمة على نفس الموقع والمتصفح، يحاول الإصدار الجديد نقل بياناتها تلقائيًا.
